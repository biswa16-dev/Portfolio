## 🌟 Features

- **Modern & Immersive UI**: Full-bleed animated hero video with dynamic typography.
- **Dynamic Content Sections**: Cleanly separated sections for About, Skills, Activity, Projects, and Experience.
- **Responsive Design**: Built with Tailwind CSS, ensuring a seamless experience across mobile, tablet, and desktop.
- **Real-time API Integrations**: Live GitHub and LeetCode stats fetcher to show coding activity.
- **Contact Form Integration**: Connected to an Express API backend for seamless messaging.
- **Downloadable Assets**: One-click download for my latest CV/Resume.

## 🛠️ Tech Stack

This project is structured as a full-stack application.

**Frontend (`/client`)**
- React 19 + TypeScript
- Vite (Build Tool)
- Tailwind CSS (Styling)
- Framer Motion (Animations)
- Firebase Hosting (Deployment)

**Backend (`/server`)**
- Node.js + Express.js
- Custom API Integrations

## 🚀 Getting Started

If you want to run this project locally, follow the steps below.

### 1. Clone the repository

```bash
git clone https://github.com/biswa1601nk-hub/Portfolio.git
cd Portfolio
```

### 2. Start the Frontend

Open a terminal and navigate to the `client` directory:

```bash
cd client
npm install
npm run dev
```

The frontend will be available at `http://localhost:5173`.

### 3. Start the Backend

Open a **new** terminal and navigate to the `server` directory:

```bash
cd server
npm install
npm run dev
```

The backend API will run on `http://localhost:5000` (or whichever port is defined in your `.env` file).
